# 📦 mods/

Every mod in this repo lives here, one folder per mod. Each folder is
self-contained — README, `workshop.txt`, and the full
`Contents/mods/<ModId>/` tree — so it can be copied straight into
`~/Zomboid/Workshop/` for testing or uploaded to the Steam Workshop.

## Mods

| Folder | Mod | Status |
|--------|-----|--------|
| [electric-scooter](./electric-scooter) | ⚡ Electric Scooter | ✅ v1.0.0 (assets pending) |

> Want to add one? Run `./scripts/new-mod.sh <folder> <ModId> "Display Name"`
> from the repo root — it scaffolds the whole layout here for you.

See the root [README](../README.md) and [ROADMAP](../ROADMAP.md) for the
project overview and queue.

# Security Policy

These mods are client-side game scripts for [Project Zomboid](https://projectzomboid.com).
There is no network service, no user data, and no executable distribution surface.

## Reporting a Vulnerability

If you believe you've found a security-relevant issue — for example a Lua
script that could be used to crash a multiplayer server, leak save data, or
escalate permissions in-game — please **do not open a public issue**.

Instead, contact the maintainer privately:

- GitHub: [@player585](https://github.com/player585)

You should expect an acknowledgement within 7 days.

## Supported Versions

Only the latest tagged release of each mod is supported. Older versions will
not receive backported fixes.

| Mod | Supported version |
|-----|-------------------|
| Electric Scooter | latest `v1.x` |
